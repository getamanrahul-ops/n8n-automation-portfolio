# n8n Automation Portfolio

A collection of n8n workflows built for real business use, task automation, lead handling, equipment logging, and content pipelines. Each folder contains the exported workflow JSON (credentials and instance-specific IDs replaced with placeholders) plus a README covering what it does, how it works, and how to set it up.

## Workflows

| Workflow | Description |
|---|---|
| calendly-to-slack-notifier | Real-time Slack + Google Sheets notifications for new Calendly bookings, built around Calendly's Free-plan webhook limitation |
| task-reminder-bot | Two-workflow Telegram bot that assigns, tracks, and chases recurring tasks via a Google Sheet, polling-based, no webhook |
| telegram-equipment-logger | Turns a captioned Telegram photo into a serial-numbered, filed equipment record in Sheets + Drive |
| raha-linkedin-pipeline | RSS-to-LinkedIn content pipeline: trending AEC topic to AI-drafted post + image to human review via Telegram |
